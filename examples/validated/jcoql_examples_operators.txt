==============================================
JCOQL+ EXAMPLES - OPERATORI E COSTRUTTI BASE
Sostituisce jcoql_examples.txt, EXTENDED, EDGE_CASES, INRANGE
(quei 4 file usavano quasi solo collezioni inventate - stores, apartments,
customers, sales, ecc. - mai esistite in nessun database reale collegato)
==============================================

ESEMPIO 1: Comparazione Numerica Semplice
----------------------------------------------
Descrizione: Prodotti con prezzo superiore a 100.
Query:
GET COLLECTION products;
FILTER CASE WHERE .price > 100 KEEP OTHERS;

ESEMPIO 2: Logica AND
----------------------------------------------
Descrizione: Prodotti di elettronica con prezzo inferiore a 500 e in stock.
Query:
GET COLLECTION products;
FILTER CASE WHERE .category = 'electronics' AND .price < 500 AND .stock > 0 KEEP OTHERS;

ESEMPIO 3: Logica OR
----------------------------------------------
Descrizione: Ristoranti a Roma o Firenze.
Query:
GET COLLECTION restaurants;
FILTER CASE WHERE .city = 'Roma' OR .city = 'Firenze' KEEP OTHERS;

ESEMPIO 4: Range Numerico con Estremi Inclusi
----------------------------------------------
Descrizione: Prezzo tra 50 e 150 euro, estremi inclusi.
Query:
GET COLLECTION products;
FILTER CASE WHERE .price IN_RANGE [ 50 , 150 ] KEEP OTHERS;

ESEMPIO 5: Range Numerico con Estremi Esclusi
----------------------------------------------
Descrizione: Sconto strettamente tra 10 e 30 (estremi esclusi).
Query:
GET COLLECTION products;
FILTER CASE WHERE .discount IN_RANGE ( 10 , 30 ) KEEP OTHERS;

ESEMPIO 6: Verifica Assenza Campo (WITHOUT)
----------------------------------------------
Descrizione: Ordini senza numero di tracciamento assegnato.
Query:
GET COLLECTION orders;
FILTER CASE WHERE WITHOUT .tracking_number KEEP OTHERS;

ESEMPIO 7: Verifica Presenza Campo (WITH)
----------------------------------------------
Descrizione: Prodotti che hanno una marca registrata.
Query:
GET COLLECTION products;
FILTER CASE WHERE WITH .brand KEEP OTHERS;

ESEMPIO 8: Null Check Esplicito (FIELD ... IS NULL)
----------------------------------------------
Descrizione: Prodotti dove il campo marca è esplicitamente null.
Query:
GET COLLECTION products;
FILTER CASE WHERE FIELD .brand IS NULL KEEP OTHERS;

ESEMPIO 9: Null Check Esplicito (FIELD ... IS NOT NULL)
----------------------------------------------
Descrizione: Ordini dove il numero di tracciamento è valorizzato.
Query:
GET COLLECTION orders;
FILTER CASE WHERE FIELD .tracking_number IS NOT NULL KEEP OTHERS;

ESEMPIO 10: SAVE AS con Database Obbligatorio
----------------------------------------------
Descrizione: Filtra gli hotel a Milano e salva il risultato come nuova collezione.
Query:
GET COLLECTION hotels;
FILTER CASE WHERE .location.city = 'Milano' KEEP OTHERS;
SAVE AS hotels_milano@jcoql_test;

ESEMPIO 11: Condizioni Complesse con Parentesi
----------------------------------------------
Descrizione: Query con precedenza esplicita fra AND e OR.
Query:
GET COLLECTION products;
FILTER CASE WHERE ( .category = 'electronics' OR .category = 'sports' ) AND .price < 300 KEEP OTHERS;

ESEMPIO 12: Negazione Semplice
----------------------------------------------
Descrizione: Prodotti non della categoria food.
Query:
GET COLLECTION products;
FILTER CASE WHERE NOT .category = 'food' KEEP OTHERS;

ESEMPIO 13: Negazione Complessa
----------------------------------------------
Descrizione: Prodotti che non sono contemporaneamente esauriti e senza sconto.
Query:
GET COLLECTION products;
FILTER CASE WHERE NOT ( .stock = 0 AND .discount = 0 ) KEEP OTHERS;

ESEMPIO 14: Range con Valori Decimali
----------------------------------------------
Descrizione: Rating dei prodotti tra 3.5 e 4.5.
Query:
GET COLLECTION products;
FILTER CASE WHERE .rating IN_RANGE [ 3.5 , 4.5 ] KEEP OTHERS;

ESEMPIO 15: Range Multipli con OR
----------------------------------------------
Descrizione: Totale ordine tra 0 e 50 oppure tra 500 e 1000.
Query:
GET COLLECTION orders;
FILTER CASE WHERE .total IN_RANGE [ 0 , 50 ] OR .total IN_RANGE [ 500 , 1000 ] KEEP OTHERS;

ESEMPIO 16: WITHOUT Multiplo con AND
----------------------------------------------
Descrizione: Prodotti senza marca e senza sconto registrati.
Query:
GET COLLECTION products;
FILTER CASE WHERE WITHOUT .brand AND WITHOUT .discount KEEP OTHERS;

ESEMPIO 17: DROP OTHERS
----------------------------------------------
Descrizione: Mantieni solo i prodotti esauriti (scarta tutto il resto).
Query:
GET COLLECTION products;
FILTER CASE WHERE .stock = 0 DROP OTHERS;

ESEMPIO 18: Confronto su Campo Annidato
----------------------------------------------
Descrizione: Hotel nella città di Torino (campo annidato location.city).
Query:
GET COLLECTION hotels;
FILTER CASE WHERE .location.city = 'Torino' KEEP OTHERS;

ESEMPIO 19: SIZE su Array
----------------------------------------------
Descrizione: Ordini con più di 3 articoli nel carrello.
Query:
GET COLLECTION orders;
FILTER CASE WHERE SIZE(.items) > 3 KEEP OTHERS;

ESEMPIO 20: Uguaglianza Booleana Esplicita
----------------------------------------------
Descrizione: Prodotti biologici con posti a sedere esterni (confronto esplicito con true).
Query:
GET COLLECTION restaurants;
FILTER CASE WHERE .outdoor_seating = true AND .gluten_free_menu = true KEEP OTHERS;

ESEMPIO 21: GET COLLECTION da una risorsa web
----------------------------------------------
Descrizione: Recupera un documento JSON pubblicato a un URL (non da un database).
Query:
GET COLLECTION FROM WEB 'https://api.esempio.it/dati.json';

ESEMPIO 22: GET COLLECTION da un file locale
----------------------------------------------
Descrizione: Carica una collezione da un file JSON locale sul server (non da un database).
Query:
GET COLLECTION FROM FILE 'dati_locali.json';

ESEMPIO 23: GENERATE BUILD - restringere/rinominare i campi restituiti
----------------------------------------------
Descrizione: Prodotti con prezzo positivo, mostrando solo nome e prezzo rinominato in "costo".
Query:
GET COLLECTION products;
FILTER CASE WHERE .price > 0 GENERATE BUILD { .name: .name, .costo: .price } KEEP OTHERS;

ESEMPIO 24: GENERATE ADD FIELDS - aggiungere un campo mantenendo gli altri
----------------------------------------------
Descrizione: Ordini con priorità urgente, aggiungendo un campo "verificato" con il valore del campo status esistente.
Query:
GET COLLECTION orders;
FILTER CASE WHERE .priority = 'urgent' GENERATE ADD FIELDS { .verificato: .status } KEEP OTHERS;

ESEMPIO 25: GENERATE REMOVE FIELDS - togliere un campo dal risultato
----------------------------------------------
Descrizione: Ristoranti con rating alto, escludendo il campo descrizione dal risultato.
Query:
GET COLLECTION restaurants;
FILTER CASE WHERE .rating >= 4 GENERATE REMOVE FIELDS { .description } KEEP OTHERS;

ESEMPIO 26: GENERATE senza condizione - trasforma tutti i documenti
----------------------------------------------
Descrizione: Da tutti i prodotti, mostra solo nome e categoria (nessun filtro, solo restrizione dei campi).
Query:
GET COLLECTION products;
FILTER GENERATE BUILD { .name: .name, .categoria: .category };

ESEMPIO 27: GET DICTIONARY + TRANSLATE - tradurre un valore tramite un dizionario
----------------------------------------------
Descrizione: Prodotti con il nome della categoria tradotto/mappato tramite un dizionario caricato da un'altra collezione (es. categorie con codice -> nome esteso).
Query:
GET DICTIONARY categories@jcoql_test AS catdict;
GET COLLECTION products;
FILTER GENERATE ADD FIELDS { .category_translated: TRANSLATE(.category, catdict) };
