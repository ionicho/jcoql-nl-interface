Titolo: Prodotti sotto soglia prezzo
Descrizione: Prodotti con prezzo inferiore a 50
Query: GET COLLECTION products; FILTER CASE WHERE .price < 50 KEEP OTHERS;

Titolo: Ordini confermati
Descrizione: Ordini con stato uguale a confermato
Query: GET COLLECTION orders; FILTER CASE WHERE .status = 'confirmed' KEEP OTHERS;

Titolo: Prodotti elettronica economici
Descrizione: Prodotti categoria elettronica con prezzo minore di 100
Query: GET COLLECTION products; FILTER CASE WHERE .category = 'electronics' AND .price < 100 KEEP OTHERS;

Titolo: Ordini spediti costosi
Descrizione: Ordini spediti con totale maggiore di 500
Query: GET COLLECTION orders; FILTER CASE WHERE .status = 'shipped' AND .total > 500 KEEP OTHERS;

Titolo: Ristoranti Roma aperti
Descrizione: Ristoranti a Roma con stato aperto
Query: GET COLLECTION restaurants; FILTER CASE WHERE .city = 'Roma' AND .status = 'open' KEEP OTHERS;

Titolo: Prodotti biologici scontati
Descrizione: Prodotti bio con sconto maggiore di 10
Query: GET COLLECTION products; FILTER CASE WHERE .organic = true AND .discount > 10 KEEP OTHERS;

Titolo: Prezzi fascia media
Descrizione: Prodotti con prezzo tra 50 e 150 inclusi
Query: GET COLLECTION products; FILTER CASE WHERE .price IN_RANGE [50, 150] KEEP OTHERS;

Titolo: Ordini senza tracking
Descrizione: Ordini senza numero tracking
Query: GET COLLECTION orders; FILTER CASE WHERE FIELD .tracking_number IS NULL KEEP OTHERS;

Titolo: Prodotti economici o scontati
Descrizione: Prodotti con prezzo minore di 30 o sconto maggiore di 20
Query: GET COLLECTION products; FILTER CASE WHERE .price < 30 OR .discount > 20 KEEP OTHERS;

Titolo: Ordini urgenti o prioritari
Descrizione: Ordini con priorità alta o urgente
Query: GET COLLECTION orders; FILTER CASE WHERE .priority = 'high' OR .priority = 'urgent' KEEP OTHERS;

Titolo: Prodotti con recensioni
Descrizione: Prodotti con almeno 1 recensione
Query: GET COLLECTION products; FILTER CASE WHERE SIZE(.reviews) > 0 KEEP OTHERS;

Titolo: Solo prodotti esauriti
Descrizione: Filtra e mantiene solo prodotti con stock zero
Query: GET COLLECTION products; FILTER CASE WHERE .stock = 0 DROP OTHERS;
