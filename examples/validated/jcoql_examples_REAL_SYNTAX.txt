# --- BASIC FILTERS (10) ---
Titolo: Hotel in città specifica
Descrizione: Hotel a Firenze
Query: GET COLLECTION hotels; FILTER CASE WHERE .city = 'Firenze' KEEP OTHERS;

Titolo: Prodotti sotto soglia prezzo
Descrizione: Prodotti con prezzo inferiore a 50
Query: GET COLLECTION products; FILTER CASE WHERE .price < 50 KEEP OTHERS;

Titolo: Utenti maggiorenni
Descrizione: Utenti con età maggiore o uguale a 18
Query: GET COLLECTION users; FILTER CASE WHERE .age >= 18 KEEP OTHERS;

Titolo: Ordini confermati
Descrizione: Ordini con stato uguale a confermato
Query: GET COLLECTION orders; FILTER CASE WHERE .status = 'confirmed' KEEP OTHERS;

Titolo: Prodotti disponibili
Descrizione: Prodotti con quantità maggiore di zero
Query: GET COLLECTION products; FILTER CASE WHERE .quantity > 0 KEEP OTHERS;

Titolo: Clienti attivi
Descrizione: Clienti con campo attivo uguale a true
Query: GET COLLECTION customers; FILTER CASE WHERE .active = true KEEP OTHERS;

Titolo: Email verificate
Descrizione: Utenti con email verificata
Query: GET COLLECTION users; FILTER CASE WHERE .email_verified = true KEEP OTHERS;

Titolo: Documenti recenti
Descrizione: Documenti con anno maggiore di 2023
Query: GET COLLECTION docs; FILTER CASE WHERE .year > 2023 KEEP OTHERS;

Titolo: Prezzi bassi
Descrizione: Articoli con costo minore o uguale a 20
Query: GET COLLECTION items; FILTER CASE WHERE .cost <= 20 KEEP OTHERS;

Titolo: Quantità sufficiente
Descrizione: Magazzino con stock maggiore o uguale a 100
Query: GET COLLECTION warehouse; FILTER CASE WHERE .stock >= 100 KEEP OTHERS;
